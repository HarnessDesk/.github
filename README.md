# .github

The HarnessDesk organisation profile.

`profile/README.md` is what renders at the top of
[github.com/HarnessDesk](https://github.com/HarnessDesk). Nothing else here is
special: the org's community health files (code of conduct, contributing guide,
security policy, issue templates) live in
[HarnessDesk/HarnessDesk](https://github.com/HarnessDesk/HarnessDesk), which is
also where the product itself is.

The screenshots the profile links are hot-linked from that repository's `main`,
so they stay in step with the app rather than drifting in a second copy.
